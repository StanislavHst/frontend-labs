# Лабораторна робота №2 — Інтерактивний світлофор

Продовження ЛР1 у тому самому Vite-проєкті (каталог `laba1`).

Запуск: `npm install`, потім `npm run dev`.
Перевірки: `npm run build` і `npm run lint`.

- `App` показує один світлофор і передає початкову орієнтацію.
- `TrafficLights` зберігає активний колір, лічильники й орієнтацію через `useState`.
- `Light` отримує колір, активність і callback `onSelect` через `props`.
- Натискання вибирає колір і збільшує його лічильник, навіть якщо він уже активний.
- `StatsBar` отримує статистику через `props`, без власного стану.
- Загальна кількість кліків обчислюється як сума трьох лічильників.
- Зміна орієнтації зберігає активний колір і статистику.
